## LEGS LAW (Jimmy, 2026-11-05 12:54; SCOPED by Jimmy 13:17)
Within SEQUENCE 1 (the strike) the legs are PLANTED: same position in the scene in every frame — feet, leg angles, stance identical frame to frame; only the neck/head/body above the hips animate. The legs-fixed rule applies ONLY to sequence 1 — later sequences (e.g. walking) move their legs as their content requires. BUT: EVERY sequence must START with the bird's legs in the same position as sequence 1's start — sequence 1's opening stance is the canonical HOME STANCE, the chaining anchor for the whole set. (Prompt text alone does NOT hold legs — the model re-invents the stance per drawing; measured across the strike set 2026-11-05.)

## HOME FRAME RULE (Jimmy, 2026-11-05 13:18)
The bird always starts in the same position overall. EVERY sequence starts AND ends on the SAME frame — the home frame, which is sequence 1's opening drawing (home stance, home position). A sequence may do anything in the middle (walk, strike, preen) but must resolve back to the home frame at its end. Consequence: any sequence can follow any other with no join problem. (This subsumes the earlier "sequences start with seq-1 legs" rule and completes the position-continuity program note.)

## NO-CROP RULE + HOME FRAME APPROVAL GATE (Jimmy, 2026-11-05 13:43)
"no dont crop." The bird is NEVER cropped by the frame edge in any sequence — the whole bird sits inside the frame (the fresh build's registration shift pushed the rear off the left edge; the source drawing was whole — the transform caused it). The first frame is redone (whole bird, colorized) and comes to Jimmy for APPROVAL before any more animation sequence work proceeds. Nothing assembles against an unapproved home frame.

## DERIVATION METHOD (Jimmy, 2026-11-05 13:46)
Animation is DERIVED FROM A REAL SEQUENCE in the reference library: pick one real ~5 s strike sequence; extract its frames at 12 fps (60 reference frames); timing, spacing, and poses come from the real bird; every drawing is CHECKED frame-by-frame against its real counterpart. This supersedes invented timing/spacing (the abstracted canon timings stand as background knowledge, not as the animation's source). Drawing technique (anchored edits, breakdown discipline) still applies, now driven by the reference frames. The home frame's pose keys to the chosen sequence's opening stance.

## ATTRIBUTION RULE (Jimmy, 2026-11-05 13:47)
Any video source used for derivation is attributed in the program comments (and in the sequence's manifest + timing metadata): creator, platform, original identifier/URL, local filename, window used.

## SUPERSESSION (Jimmy, 2026-11-05 13:57)
The clip-derivation method above is SET ASIDE, by Jimmy's reasoning: a borrowed sequence starts wherever that bird stood — there is no way to start every sequence from the same frame, which the home-frame architecture requires. PRODUCTION STANDARD going forward: each sequence is redone FROM ITS OWN ORIGINAL SOURCES (the strike's: the canonical keys, photo references, and approved drawing) at full 12 fps density from the start — smoothness comes from density + spacing against the sequence's own keys, not from footage. The attribution rule stands for any video source actually used.
